# סמוך (Smoch)

פלטפורמת ביקורות ציבוריות על קורסי מסחר, קבוצות איתותים, ליווי ובוטים בישראל.

## מצב נוכחי: שלב 1, אבטיפוס

ממשק בלבד עם נתוני דמה (`src/lib/data.ts`). כל החברות והביקורות בדויות.
אין עדיין מסד נתונים או התחברות אמיתית.

דפים:
- `/` דף הבית: חיפוש, הכי מומלצים, הדירוג הנמוך ביותר, ביקורות אחרונות
- `/companies` רשימת חברות עם חיפוש, סינון לפי קטגוריה ומיון
- `/company/[slug]` דף חברה: ציון אמינות, התפלגות, ביקורות, תגובות החברה, דיווח
- `/company/[slug]/review` כתיבת ביקורת: התחברות, דירוג, צירוף קבלה, אישור כללים
- `/add-company` הוספת חברה לבדיקה
- `/guidelines` כללי כתיבה, חישוב הציון ומדיניות הסרה

## הרצה

```bash
npm install
npm run dev
```
