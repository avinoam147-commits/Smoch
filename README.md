# סמוך (Smoch)

פלטפורמת ביקורות ציבוריות על קורסי מסחר, קבוצות איתותים, ליווי ובוטים בישראל.

**להקמה בפועל (Supabase, Google, Vercel): ראו [SETUP.md](SETUP.md).**

## מה יש באתר

**לגולשים**
- דף בית, רשימת חברות עם חיפוש, סינון ומיון, ודף לכל חברה עם ציון אמינות, התפלגות וביקורות.
- התחברות עם Google. מוצגים רק שם פרטי ואות ראשונה.
- דירוג מהיר בכוכבים, עם טקסט לא חובה. עריכה ומחיקה, וצירוף קבלה לאימות רכישה (קובץ פרטי שנמחק אחרי הבדיקה).
- הציון מוצג רק אחרי 10 דירוגים, עם הסבר גלוי למה הוא מוסתר עד אז.
- סימון ״מועיל״, דיווח על ביקורת, הצעת חברה חדשה (עם בדיקה מול רשם החברות) ובקשה לנהל דף חברה.
- דף חשבון: שם מוצג, התראות, אימות טלפון ב-SMS, הביקורות שלי ומחיקת חשבון.
- נציג/ה מאומת/ת של חברה יכול/ה להגיב לביקורות בפומבי.

**פאנל ניהול** (`/admin`, מוסתר מכל מי שאינו מנהל)
- סקירה עם תורי עבודה.
- חברות: הוספה, עריכה, לוגו, אימות מול רשם החברות, אישור או דחייה, הסתרה, מחיקה והסרת נציגים.
- ביקורות: הוספה (מסומנת ״הוזנה על ידי הצוות״), עריכה, פרסום, הסתרה, מחיקה ועריכת תגובות.
- דיווחים, קבלות ובקשות ניהול.
- משתמשים: מינוי מנהלים והשעיה.
- הגדרות: פרסום אוטומטי, חובת טלפון ומגבלות יומיות.
- יומן פעולות שנרשם אוטומטית במסד הנתונים.

**מאחורי הקלעים**
- כל כלל חשוב נאכף במסד הנתונים (RLS וטריגרים), לא רק בממשק: ביקורת אחת לחברה, מגבלה יומית, סינון טלפונים, קישורים והאשמות, ושדה ״רכישה מאומתת״ שרק מנהל יכול לסמן.
- ציון אמינות: ממוצע בייסיאני, עם משקל גבוה יותר לרכישה מאומתת ונמוך יותר לביקורות ישנות.
- SEO: מפת אתר, robots ו-JSON-LD עם דירוג מצטבר.
- התראות במייל דרך Resend (אופציונלי).
- כשאין חיבור ל-Supabase, האתר עולה במצב הדגמה עם נתונים בדויים.

## מבנה

```
supabase/migrations/   סכמת מסד הנתונים, הרשאות וטריגרים
supabase/seed.sql      נתוני דמה לפיתוח מקומי בלבד
src/lib/               גישה לנתונים, התחברות, מיילים, רשם החברות
src/app/               דפי האתר ו-server actions
src/app/admin/         פאנל הניהול
tests/                 בדיקות מסד נתונים ובדיקות דפדפן
```

## פיתוח

```bash
npm install
npx supabase start
npm run db:reset
npm run dev
```

בדיקות: `npm run test:db` (17 בדיקות אבטחה במסד) ו-`npm run test:e2e` (13 תרחישים בדפדפן, מול `next start` על פורט 3000).
